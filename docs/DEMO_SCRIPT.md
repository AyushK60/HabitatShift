# 90-second demo script

Record at 1440x900 (or run `tools/visual/capture_demo_gif_frames.mjs` for
stills). Start the app with `start.bat`. Narration is deliberately short and
claims only what the audits support.

| Time | Screen | Say |
|---|---|---|
| 0:00 | Landing page, swipe on the hero image | "Six study areas, real Sentinel-2 scenes, every number traceable to a named scene." |
| 0:10 | Atlas gallery, open **Chilika Lake** | "Two matched seasons, five years apart, on one pixel grid." |
| 0:20 | Swipe view, then **Change** layer | "Candidate change, not verified change. The platform says that on every layer." |
| 0:35 | **Quality** layer | "Cloud and snow masking is visible, and only shared-valid pixels are measured." |
| 0:45 | Analysis dock: threshold sensitivity chart | "Result depends on threshold, so the sensitivity is shown, not hidden." |
| 0:55 | **Western Ghats** NDVI | "Essentially stable. The honest output is that no deforestation claim is possible." |
| 1:05 | Research Mode, ML table | "Random Forest agreement with ESA WorldCover. Not ground truth. Weak classes show 'not reported'." |
| 1:15 | Stop the backend, reload | "The whole product also runs offline as a static showcase." |
| 1:25 | README audit line | "4,111 independent checks, and a study regenerated byte-identically from source." |

Avoid saying: "detects deforestation", "predicts", "accuracy" (use "agreement"),
or anything about causes of change.
